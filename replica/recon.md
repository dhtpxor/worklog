## Core loop

사용자가 랭킹·검색·브랜드로 패션 상품을 발견하고, 후기와 사이즈 추천으로 확신을 얻어, 등급 할인·쿠폰·적립금을 적용해 결제한 뒤, 후기를 남겨 적립금을 받고 다시 구매한다. (브랜드는 파트너 센터로 상품을 올리고 주문을 처리한다.)

## Flows

```
F01 상품을 찾아 구매한다 (핵심 루프)
    S01 홈 -> S05 랭킹 또는 S04 검색 -> S03 목록(필터) -> S08 상세 -> S10 장바구니 -> S11 주문서 -> S12 완료
    happy path clicks: 8 (홈→랭킹→상품→옵션 선택→장바구니→장바구니 보기→주문하기→결제)
    edge: 옵션 품절(재입고 알림), 쿠폰 적용 불가 상품, 적립금 최소 사용 금액, 결제 실패, 비로그인 상태에서 장바구니 담기

F02 사이즈를 확신하고 산다
    S08 상세 -> 사이즈표/실측 -> 사이즈 추천(구매내역 또는 치수 입력) -> S09 후기(사이즈 체감) -> 옵션 선택
    happy path clicks: 4
    edge: 구매 이력 없음, 브랜드가 실측 미제공

F03 주문을 추적하고 교환/반품한다
    S16 마이 -> S13 주문내역 -> S14 클레임(사유 → 회수 방법 → 반송장/배송비) -> S13 상태 갱신
    happy path clicks: 6
    edge: 상품준비중 이후 교환 불가, 9일 내 반송장 미입력 시 취소, 자동회수 미제공 업체, 교환 배송비 결제 실패

F04 후기를 써서 적립금을 받는다
    S16 마이 -> S20 후기 관리(작성 가능 목록) -> 유형 선택 -> 작성 -> 적립금 지급(S19)
    happy path clicks: 5
    edge: 사진 없는 후기는 적립 감액, 도용·개인정보 노출 반려, 한 달 후기는 배송완료 후 일정 기간 뒤에만 가능
```

## Out of scope (cannot or should not be cloned)

- **브랜드·상품·이미지·후기 데이터 자체**: 무신사가 보유한 입점 브랜드 네트워크와 콘텐츠. 클론은 빈 카탈로그로 시작하고 파트너 센터로 채운다.
- **멀티 스토어(뷰티·아울렛·부티크·키즈·플레이어·스니커즈)**: 각각 별도 MD·브랜드 계약이 필요한 사업 단위. 구조는 "스토어 탭"으로만 남긴다.
- **무신사페이(자체 간편결제 사업)·무신사머니 상품권·제휴 카드 할인**: 전자금융업 등록과 제휴 계약이 필요. 클론은 외부 PG + 적립금으로 대체.
- **무신사 라이브(라이브 커머스), 래플, 매거진/콘텐츠 제작, 무신사 크루 프로그램**: 운영 조직이 있는 콘텐츠·이벤트 사업.
- **오프라인 매장 연동(스탠다드·엠프티), 오프라인 후기 적립, 글로벌 배송·관세**: 물류·법률 범위 밖.
- **유즈드(중고 거래), 솔드아웃(리셀), 29CM 통합 등급**: 별도 서비스.
- **AI 이미지 검수 모델, ChatGPT 앱(MCP)**: 기능 흐름(검수 대기 상태)만 재현.
- **무신사 로고·브랜드명·카피·UI 에셋**: 클린룸 원칙. replica-brand에서 새로 만든다.
