# TrueUnit — 거래 시점 진품 판정·보증 플랫폼 (MVP)

기획안 [docs/ideas/anti-counterfeit-transaction-authenticity-platform.md](../docs/ideas/anti-counterfeit-transaction-authenticity-platform.md) 를 구현한 첫 버전입니다.
브랜드 대신 리스팅을 지우는 서비스가 아니라, **중고·리셀 플랫폼과 리테일러가 실물 1개의 진위를 거래 순간에 판정하고 보증**하도록 돕습니다.

## 무엇이 들어 있나

| 기능 | 하는 일 | 위치 |
|---|---|---|
| 촬영 가이드 | 판매자에게 부위별 촬영 링크를 보내고, 올리는 즉시 흐림·노출·해상도를 검사해 다시 찍게 함 | `public/capture.*`, `src/imaging/quality.js` |
| AI 체크포인트 분석 | Claude 비전이 부위별 관찰과 이상 정도(none/minor/major/판단 불가)를 구조화해 기록. 결론은 내리지 않음 | `src/ai/vision.js` |
| 위험 점수 | AI 관찰·누락 부위·사진 품질·시세 대비 가격·판매자 이력·사진 재사용을 근거별 가산점으로 합산 | `src/risk.js` |
| 라우팅 | 저위험이면 자동 통과, 나머지는 검수 대기열(우선 검수 분리), 저위험 중 일부는 품질 감사로 사람에게 | `src/risk.js` |
| 사진 재사용 탐지 | 다른 판매자·다른 플랫폼 거래에 올라온 사진과 거의 같으면 표시 (다른 플랫폼 건은 id 를 숨김) | `src/imaging/hash.js` |
| 검수사 콘솔 | 대기열, 부위별 사진과 AI 관찰, 근거 부위 지정, 판정 저장, 청구 처리 | `public/console.*` |
| 진품 보증 | 점수·검수 결과로 견적, 발행, 청구, 재검수, 지급. 카테고리별 손해율과 자동 판매 중단 | `src/guarantee.js` |
| UnitPrint 개체 지문 | 표면 미세패턴을 등록하고 나중에 재촬영과 대조. 반품 바꿔치기, 플랫폼 간 재판매 재검수 생략 | `src/imaging/fingerprint.js` |
| 지표 | 자동 통과율, 검수 비율, 가품 포착률, 진품 오경보, 감사 표본 오통과, 손해율, 처리 시간 | `src/metrics.js` |
| 웹훅 | 판정·보증·청구 이벤트를 HMAC 서명과 함께 플랫폼에 전송 | `src/webhooks.js` |

## 실행

```bash
cd trueunit
npm install
cp .env.example .env   # 값 채우기 (ANTHROPIC_API_KEY 없이도 동작)
set -a; . ./.env; set +a
npm start
```

첫 실행 때 데모 테넌트와 키 3개(platform, inspector, admin)가 콘솔에 한 번만 출력됩니다. 새 플랫폼을 추가하려면 `npm run seed -- "플랫폼 이름"` 을 실행합니다.

- 검수 콘솔: `http://localhost:8787/console` (검수사 또는 관리자 키로 접속)
- 판매자 촬영 링크: 거래 건을 만들면 `capture_url` 로 받습니다
- API 사용법: [docs/API.md](docs/API.md)

```bash
npm test   # 단위·통합 테스트 (AI 는 가짜 클라이언트로 대체)
```

## 서버에 올리기 (Docker)

저장소의 `Dockerfile` 로 어느 호스팅에나 올릴 수 있습니다. 이 이미지는 빌드·실행·헬스체크·재시작 후 데이터 유지까지 확인했습니다.

```bash
docker build -t trueunit .
docker run -d --name trueunit -p 8787:8787 -v trueunit-data:/data \
  -e ANTHROPIC_API_KEY=sk-ant-... -e PUBLIC_BASE_URL=https://내도메인 trueunit
docker logs trueunit   # 첫 실행 때 키 3개가 한 번만 출력됩니다
```

호스팅에 올릴 때 지켜야 할 것
- **`/data` 에 영구 디스크(볼륨)를 붙여야 합니다.** 붙이지 않으면 재시작·재배포 때 거래 건, 사진, 키가 모두 사라집니다.
- 그래서 디스크가 없는 무료 플랜(잠들었다 깨는 방식 포함)은 시연용으로만 쓸 수 있습니다.
- Render 는 Docker 웹 서비스 + Disk(마운트 경로 `/data`), Railway 는 Docker 서비스 + Volume(`/data`) 으로 설정합니다. 저장소의 `trueunit` 폴더를 루트 디렉터리로 지정합니다.
- 환경변수 `ANTHROPIC_API_KEY`, `PUBLIC_BASE_URL` 을 호스팅 설정 화면에서 넣습니다. `PORT` 는 호스팅이 정해 주는 값을 그대로 씁니다.
- 첫 실행 키는 호스팅의 로그 화면에 한 번 출력됩니다. 보관한 뒤에는 로그 보존 기간을 확인하세요.

## 흐름

```
플랫폼 ──POST /v1/cases──▶ 거래 건 + 촬영 링크
판매자 ──촬영 링크──▶ 부위별 업로드 (즉시 화질 피드백) ──제출──▶
   Claude 비전 관찰 + 가격·판매자·재사용 신호 ──▶ 위험 점수 + 근거
      ├─ 저위험·완비·강한 위험 신호 없음 ──▶ 자동 통과 (일부는 감사 표본으로 사람 확인)
      └─ 그 외 ──▶ 검수 대기열 (높음은 우선) ──▶ 검수사 판정
플랫폼 ◀──웹훅 case.assessed / case.verdict──
플랫폼 ──보증 견적 → 발행──▶ 구매자 신고 시 청구 ──▶ 재검수 ──▶ 지급 또는 기각 ──▶ 손해율 → 자동 판매 중단
```

## 설계 원칙

- **AI 는 판정하지 않습니다.** 부위별 관찰과 이상 정도만 기록하고, 가품 확정은 언제나 사람이 합니다. 자동 결론은 "통과" 또는 "검수 필요" 두 가지뿐입니다.
- **모든 점수에 근거가 붙습니다.** 분쟁 때 "AI 가 그랬다"로는 설명이 되지 않기 때문입니다.
- **판매자에게는 점수와 기준을 보여 주지 않습니다.** 위조범이 기준을 학습하지 못하게 하기 위해서입니다. 재촬영 안내만 전달합니다.
- **사진 속 글자는 데이터입니다.** 사진에 "정품 인증" 같은 문구가 있어도 AI 지시로 받아들이지 않도록 프롬프트에 명시했습니다.
- **AI 가 없거나 실패해도 멈추지 않습니다.** 그 건은 사람 검수로 넘어갑니다.

## 검증한 것과 검증하지 못한 것

확인한 것
- 테스트 29개 통과: 화질 검사, 사진 해시, 개체 지문, 위험 점수, 보증·청구·킬 스위치, HTTP 전체 흐름, 권한·테넌트 분리, 웹훅 서명, AI 실패 시 처리.
- 브라우저(Chromium)로 판매자 촬영 → 제출 → 검수사 판정 → 청구 → 관리자 지표까지 실제 화면을 돌려 오류가 없음을 확인. 모바일 폭에서 가로 스크롤 없음.
- 개체 지문은 합성 텍스처에서 같은 개체 0.93~0.97점, 다른 개체 0.09~0.10점으로 분리됨.

확인하지 못한 것
- **실제 Claude API 호출.** 개발 환경에 API 키가 없어 가짜 클라이언트로만 테스트했습니다. 요청 형식(구조화 출력, 폴백 베타)은 SDK 문서 기준으로 작성했고, 첫 실제 호출에서 응답을 확인해야 합니다.
- **AI 의 실제 판별력.** 진품·가품 실물 사진으로 측정한 적이 없습니다. 위험 점수 가중치(`src/risk.js`)와 체크포인트 가중치(`src/catalog.js`)는 초기값이며, 파일럿에서 검수사 판정과 비교해 다시 맞춰야 합니다.
- **개체 지문의 실제 성능.** 합성 이미지 결과는 실제 가죽·직조 재촬영보다 낙관적입니다. 실제 제품으로 같은 개체/다른 개체 점수 분포를 재고 일치 기준(기본 0.3)을 다시 정해야 합니다. 같은 부위를 비슷한 거리·각도로 찍는 촬영 프레임이 전제입니다.
- **보증의 법적 성격.** 보험업법상 보험 상품에 해당하는지 확인하지 않았습니다. 운영 전 법률 검토가 필요합니다.

## 운영 전에 바꿔야 할 것

- 저장소: 지금은 단일 프로세스용 JSON 파일(`data/db.json`)과 로컬 이미지 폴더입니다. 여러 인스턴스로 돌리려면 `src/store.js` 와 같은 인터페이스로 Postgres + 객체 저장소 어댑터를 붙여야 합니다.
- 요청 제한(rate limit), 키 폐기·재발급 API, 감사 로그 보관 기간, 이미지 보관·삭제 정책(개인정보), HTTPS 종단.
- AI 비용: 건당 이미지 6~8장이 들어갑니다. 파일럿에서 건당 토큰을 재서 `CLAUDE_EFFORT` 와 이미지 크기를 조정하세요. 지표 화면에 누적 토큰이 나옵니다.
